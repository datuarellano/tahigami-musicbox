                    What happens when you update?
                    
      
                        
    1. Your Music Box quietly steps into a safe setup mode built into the device.
      2. 
                        
    2. The new firmware is downloaded, double-checked for accuracy, and carefully written in.
      3. 
                        
    3. It restarts on its own and starts playing again — no buttons to press.
      4. 
                    
    
                    
    
                        Please keep the USB cable plugged in until you see Done. Your saved
                        settings come along for the ride whenever the new firmware supports them.
                        If anything looks off afterwards, just click Reconnect above. Along
                        the way your browser will ask which device to connect to — it may show up
                        with an unfriendly name like "Unknown Device"; that's just your Music Box
                        in update mode, so pick it.
                    
    
                
    
            
    

            
    
                Other versions
                
    
                    Install any other released version — handy for comparing how the Music Box
                    used to sound and behave, or for bringing a very old unit forward a step at
                    a time. None of these can talk to this app, so the Config tab locks itself
                    again until you're back on the latest version.

                        Timer
                    
      
                    
      
                        By default the Music Box plays for 40 minutes, then fades out and
                        generates a whole new piece. You can set that anywhere from 1 to 240 minutes.
                    
      

                    
      
                        

                        
      
                            
                        
      
                        
      

                        
      
                            The new length takes effect at the next regeneration.
                            
                        
      

                        
      
                            This device had a different value saved here before.
                            
                        
      
                    
      
                
      

                
      
                    
      
                        
                        Cap the volume
                    
      
                    
      
                        Set the loudest the volume knob is allowed to reach — handy for a quieter
                        room. Below the cap the knob works exactly as before; turning it further
                        past the cap just doesn't do anything more.
                    
      

                    

                    
      
                        
                    
      
                    
      Takes effect right away — saving just keeps it past a power-cycle.
      
                
      

                
      
                    
      
                        
                        LED brightness
                    
      
                    
      
                        Set how bright the breathing LED glows — turn it down for a dark room, all
                        the way off if you'd rather not see it, or past 100% for brighter than the
                        original default.
                    
      

                    

                    
      
                        
                    
      
                    
      Takes effect right away — saving just keeps it past a power-cycle.
      
                
      

                
      
                    
      
                        
                        Tempo range
                    
      
                    
      
                        Set how slow or fast the Music Box is allowed to pick its tempo, each time
                        it starts a new piece.
                    
      

                    
                    

                    
      
                        
                    
      
                    
      Takes effect right away — saving just keeps it past a power-cycle.
